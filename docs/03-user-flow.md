# Suppercook — User Flow: от регистрации до первого блюда

## Happy path

### Шаг 1 — Регистрация (≤ 30 сек)
Вход через Apple/Google в один тап (обязателен для iOS — требование App Store). Email — запасной вариант. Никаких обязательных анкет.

### Шаг 2 — Лёгкий онбординг (3 экрана, можно пропустить)
- «Что для вас важно?»: похудение / поддержание формы / просто вкусно есть.
- **Аллергии и непереносимости** — единственный обязательный вопрос (вопрос безопасности, а не персонализации).
- Целевой калораж — опционально (для v1.2), в MVP не грузим.

### Шаг 3 — Главный экран: «Что у вас в холодильнике?»
Пустое состояние с крупной кнопкой **«Добавить продукты»** и подсказкой (можно вручную, можно по фото). Второй вход — «Пропустить, хочу просто спросить у бота».

### Шаг 4 — Сбор инвентаря
1. Пользователь фотографирует продукты (или набирает текст).
2. AI распознаёт: «Я вижу: молоко, яйца (4 шт), помидоры, сыр».
3. **Экран подтверждения** — пользователь правит/удаляет/добавляет. Критично: доверять распознаванию на 100% нельзя, фрустрация от ошибок убивает удержание.
4. Сохранение в инвентарь (с единицами измерения, в граммах).

### Шаг 5 — Момент ценности: «Что приготовить?»
CTA: **«Предложи блюда»** → AI анализирует инвентарь против аллергий/предпочтений → выдаёт **3–5 вариантов карточек**: фото, название, время, сложность и бейдж **«не хватает: сметана»**.

### Шаг 6 — Выбор рецепта
Карточка: ингредиенты с граммовкой (пометка «уже есть / надо купить»), пошаговый план, таймер.

### Шаг 7 — Готовка
Режим готовки: шаг за шагом, крупная типографика, таймеры на шаги («томить 15 мин»), экран не гаснет.

### Шаг 8 — Замыкание цикла
- Недостающие ингредиенты → **«Добавить в список покупок»** → умный список уже сформирован (дедупликация, объединение «250 г сыра» из разных рецептов).
- После готовки: «Как вышло?» → сохранение в историю → мягкий оффер на следующее действие («Запланировать завтра?»).

## Edge-cases (закладывать сразу)

| Ситуация | Поведение |
|---|---|
| Отказ в доступе к камере | Ручной ввод работает всегда как fallback |
| AI недоступен / ошибка | Показать заранее закэшированные «популярные рецепты», а не ошибку |
| Пустой инвентарь | Предложения-заготовки («Базовый набор: добавить 10 частых продуктов») |
| Очень мало ингредиентов (1–2) | AI честно предлагает «купить 2 позиции и приготовить X», а не выдумывает блюда из ничего |

## Воронка для аналитики

```
установка → инвентарь собран → рецепт сгенерирован → готовка начата → блюдо приготовлено
```
